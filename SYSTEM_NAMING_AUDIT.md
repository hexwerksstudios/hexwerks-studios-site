# System Naming Audit

This internal audit separates current terms so public pages do not collapse different parts of the Death Spiral project into one product name.

## Terms Found

| Term | Current evidence | Recommended public use |
| --- | --- | --- |
| **HexFlight** | Death Spiral art, photos, and system page | The aircraft miniature system for Death Spiral. |
| **HexAxis** | Death Spiral art, prototype photos, and system page | The flight stand system used beneath aircraft. |
| **Hexlink** | Death Spiral main graphic and existing route/content | A developing tile connection or assembly term. Do not present it as the full battlefield product name until its exact role is confirmed. |
| **Death Spiral Battlefield** | Photographed WWI terrain and game setups | The current WWI battlefield set used beneath Death Spiral aircraft and HexAxis stands. |
| **Hexwerks Terrain System** | No verified product record found in the current repository | Reserve for a possible broader terrain platform only after naming and scope are approved. |

## Current Public Direction

- Use **HexFlight** for aircraft.
- Use **HexAxis** for flight stands.
- Use **Death Spiral Battlefield** for the photographed WWI battlefield set.
- Mention **Hexlink** only as developing connection or assembly terminology where necessary.
- Do not use **Hexwerks Terrain System** as a public product name yet.

## Follow-up Needed

- Confirm whether the Death Spiral Battlefield is a set within a later Hexwerks Terrain System.
- Update image labels, route names, downloads, and product copy once those decisions are recorded.
