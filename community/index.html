How to participate

Useful feedback starts with the current build.

01

Join Discord. Find the current development conversation and ask which files or tests are active.

02

Confirm the version. Rules questions and playtest notes need the exact file or build being used.

03

Report the table state. Describe what happened, what was unclear, and what choice led there.

04

Share the physical result. Print issues, painted models, stand behavior, and terrain fit belong in the record too.
